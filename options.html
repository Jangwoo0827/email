전송 방식

받은편지함 새 메일 확인 (Gmail)

Chrome에 로그인된 Gmail 세션을 사용합니다. 별도 로그인이나 API 키가 필요 없습니다. 로그인된 모든 계정을 자동으로 찾아 팝업 왼쪽에 보여줍니다.

Gmail 연결 (메일 본문 보기 · 익스텐션에서 바로 보내기)

Google 공식 Gmail API를 씁니다. 처음 한 번만 Google Cloud에서 OAuth 클라이언트 ID를 만들어 아래에 붙여넣으면 됩니다(무료).

  1. Google Cloud 콘솔에서 새 프로젝트 만들기
  2. Gmail API → 사용
  3. OAuth 동의 화면(Google 인증 플랫폼) 구성 → 대상 외부 → 테스트 사용자에 연결할 Gmail 주소들을 모두 추가
  4. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 유형 웹 애플리케이션 → 승인된 리디렉션 URI에 아래 주소 추가
  5. 만들어진 클라이언트 ID를 아래에 붙여넣고 저장 → 팝업에서 계정 선택 후 계정 연결
